# Autohand Review fonts

The report viewer embeds the approved OFL font artifacts from the Autohand
website repository. They are copied from these canonical build outputs:

- `fonts/dist/sans/AutohandSans-Regular.woff2`
- `fonts/dist/mono/AutohandMono-Regular.woff2`

Canonical repository: `autohand/autohandsite`

| Artifact | SHA-256 |
| --- | --- |
| `AutohandSans-Regular.woff2` | `00acde8ad8fb4d7dcdeb371cbb97729a5dbb8d203faca3c987281128b63893a2` |
| `AutohandMono-Regular.woff2` | `f282ee6bf3139cf8a35cabe0b9998adf0b0a7b49af8d29ce31fce436479f4a75` |

The corresponding SIL Open Font License 1.1 texts are shipped beside the
font files. Keep each license with its family when redistributing the viewer.
